เพิ่ม client ให้โฟลเดอร์นี้

เลือก client ที่ลงทะเบียนไว้แล้ว ตรวจ Client ID หากชื่อซ้ำกัน

สิทธิ์ในโฟลเดอร์นี้
ยังไม่เคยลงทะเบียน client

ใช้ callback จริงจากแอป แล้วโหลดรายการใหม่:

dodo auth add-client --name "ChatGPT" --redirect-uri "<callback URL จาก client>"
ล้าง client ที่ไม่ใช้

แสดงทะเบียน client ของทั้งเครื่อง การลบจะถอนล็อกอินและสิทธิ์ในทุกโฟลเดอร์

ไม่ลบไฟล์โปรเจกต์ งานที่เริ่มไปแล้วอาจทำต่อได้ หากต้องการถอนเฉพาะโฟลเดอร์นี้ ให้ใช้ “ถอนสิทธิ์ทั้งหมด” บนการ์ดแทน

ค่าขั้นสูง

Android / ADB

off

การเข้าถึง Android ปิดอยู่

เลือกอุปกรณ์จาก serial จริง

วิธีเชื่อมต่อและขอบเขต

ติดตั้ง Android SDK Platform-Tools เปิด USB debugging หรือ Wireless debugging แล้วกดยอมรับ RSA prompt บนมือถือ จากนั้นกด “ค้นหาอุปกรณ์ ADB”

โหมดดูอนุญาต screenshot, UI hierarchy, logcat, package และไฟล์แบบ bounded ส่วนโหมดควบคุมเพิ่ม tap/swipe/text/key, app actions, ติดตั้ง APK, push file และ advanced device-only command ทุก action ยังต้องมี dodo:exec และผ่าน trust/approval เดิม

DODO ไม่เปิด pairing, ไม่ใช้ pairing code, ไม่ root, ไม่จัดการ ADB server และไม่ถือว่า directory guard เป็น sandbox ของมือถือ

Desktop access

off

การอ่านและควบคุมหน้าต่างปิดอยู่

อนุญาต Chrome และจำสิทธิ์ไว้ 
dodo desktop allow --app com.google.Chrome --mode control --persist --yes
วิธีตั้งค่าและข้อจำกัด

รันคำสั่งด้านบนใน Terminal ที่ path ใดก็ได้ ครั้งเดียวใช้ได้ทุกโปรเจกต์ หากต้องการชั่วคราวเฉพาะ workspace ปัจจุบัน ใช้ --minutes 60 แทน --persist

ก่อนใช้งานรัน dodo setup --components desktop ใน local interactive session: macOS ใช้ Screen Recording / Accessibility, Windows ใช้ interactive desktop + UI Automation, Linux รองรับ X11/XWayland ที่มี XTEST/AT-SPI เลือก app ID ด้วย dodo desktop apps (Windows/Linux) หรือ bundle ID บน macOS

ปุ่ม “ปิดและลืมสิทธิ์” ลบสิทธิ์ที่จำไว้ทั้ง installation และหยุดคำสั่งถัดไป แต่ย้อน OS event ที่ส่งไปแล้วไม่ได้
