เพิ่ม absolute path ด้านล่าง โปรเจกต์ที่กำลังเปิดจะยังทำงานได้แม้ไม่ได้ลงทะเบียน

DODO จะบันทึก canonical realpath และ directory identity ห้ามใช้ home, filesystem root หรือ path ที่ไม่มีอยู่จริง

Desktop access

off

การอ่านและควบคุมหน้าต่างปิดอยู่

อนุญาต Chrome และจำสิทธิ์ไว้ 
dodo desktop allow --app com.google.Chrome --mode control --persist --yes

นำไปวางใน Terminal ที่อยู่ในโฟลเดอร์โปรเจกต์นี้ รันครั้งเดียวแล้วใช้ต่อเมื่อเปิด DODO ใหม่ได้ หากต้องการชั่วคราว ใช้ --minutes 60 แทน --persist

รัน dodo setup --components desktop ใน local interactive session ก่อน: macOS ใช้ Screen Recording / Accessibility, Windows ใช้ interactive desktop + UI Automation และ Linux รองรับ X11/XWayland ที่มี XTEST/AT-SPI. จากนั้นเลือก app ID ด้วย dodo desktop apps (Windows/Linux) หรือ bundle ID บน macOS แล้วอนุญาตแยกจาก trusted / bypass

ลบสิทธิ์ที่จำไว้ของโปรเจกต์นี้และหยุดคำสั่งถัดไป แต่ย้อน OS event ที่ส่งไปแล้วไม่ได้

Cloudflare Tunnel

กำลังตรวจ…

Token ใช้เฉพาะรอบที่กำลังเปิด: dodo start จะถามแบบซ่อนใน terminal แล้วส่งให้ process cloudflared โดยไม่บันทึกลง config, Keychain, Credential Manager หรือ Secret Service

กด “เปิด Tunnel รอบนี้” เพื่อเริ่มทันที ค่าในช่องจะถูกล้างหลังส่ง ไม่บันทึกลงเครื่อง และ tunnel จะหยุดพร้อม DODO

การเริ่มอัตโนมัติและค่าขั้นสูง

สำหรับรอบที่ไม่ต้องการ Tunnel ใช้ dodo start --no-tunnel Token ไม่ถูกส่งมาหรือแสดงบนหน้าเว็บนี้

กำลังโหลด…

โฟลเดอร์:

ยังไม่มี client ที่อนุญาตในโฟลเดอร์นี้

เลือกเพิ่ม client ด้านล่างเพื่อใช้การเชื่อมต่อเดิมกับโฟลเดอร์นี้

เพิ่ม client ให้โฟลเดอร์นี้

เลือก client ที่ลงทะเบียนไว้แล้ว ตรวจ Client ID หากชื่อซ้ำกัน สิทธิ์ของโฟลเดอร์อื่นจะไม่ถูกเปลี่ยน

สิทธิ์ในโฟลเดอร์นี้
ยังไม่เคยลงทะเบียน client

ใช้ callback จริงจากแอป แล้วโหลดรายการใหม่:

dodo auth add-client --name "ChatGPT" --redirect-uri "<callback URL จาก client>"
ล้าง client ที่ไม่ใช้

ส่วนนี้แสดงทะเบียน client ของทั้งเครื่อง เลือกเฉพาะตัวที่ต้องการลบ การลบจะถอนล็อกอินและสิทธิ์ของตัวนั้นในทุกโฟลเดอร์ ต้องลงทะเบียนและเชื่อมใหม่หากต้องการใช้อีก

ไม่ลบไฟล์โปรเจกต์หรือการเชื่อมต่ออื่น งานที่เริ่มไปแล้วอาจทำต่อได้ หากต้องการถอนเฉพาะโฟลเดอร์นี้ ให้ใช้ “ถอนสิทธิ์ทั้งหมด” บนการ์ดแทน
